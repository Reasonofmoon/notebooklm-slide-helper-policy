Privacy policy · 2026-10-27

Notebook Workbench for Gemini Notebook is an independent Chrome extension. It is not affiliated with, endorsed by, or sponsored by Google.

Local table tools

The extension reads tables already loaded in a supported notebook page only when the user asks it to find tables. The user chooses which tables to save. Tables, notebook page titles/URLs, capture timestamps, visible cell-link references, and row provenance are stored in `chrome.storage.local` on this browser. Imported CSV/TSV/Markdown files are processed locally. Charts and follow-up prompt templates are produced locally. No developer backend, analytics SDK, advertising tracker, or third-party telemetry is used.

Local CSV, SVG, and JSON downloads are created when the user requests them. Backups contain table data and provenance and may be sensitive. Keep them private. Table backup files do not include legacy slide API keys or saved slide prompts.

User-controlled use of Google services

When the user chooses to insert a generated prompt into a notebook, the extension fills the identified input only. It does not click Submit. After the user submits it, Google's service handles the submitted content under Google's terms and privacy policies. Existing input text is not overwritten.

The optional legacy slide Vision feature is different from local table processing. After an explicit confirmation, the extension captures the currently visible tab screenshot and sends it, together with the current draft prompt and selected analysis options, directly to `https://generativelanguage.googleapis.com/` using the user's Gemini API key. API charges may apply. Google processes that request under its applicable API terms. The developer does not receive the screenshot, prompt, or API key.

The user's Gemini API key, saved slide prompts, recent prompts, and UI preferences remain in local extension storage. Chrome local extension storage is not a dedicated encrypted password vault. Do not use Vision on screens containing sensitive information or credentials.

Permissions

`storage`: local tables, provenance, preferences, and the existing slide tools' prompts/API key.

`activeTab`: access to the currently active tab after a user action; used by the optional screenshot-based Vision feature.

Content scripts on `https://notebook.google.com/*` and `https://notebooklm.google.com/*`: explicit table collection and input filling.

`https://generativelanguage.googleapis.com/*`: direct requests for the optional Gemini Vision feature.

No broad all-sites access, cookies permission, browsing-history permission, or private Notebook RPC is used.

Retention and deletion

Saved data stays in this browser until deleted from the table library, removed through browser extension storage controls, or the extension is uninstalled. Uninstalling normally removes extension-local data. Export backups first if needed. Deleting a local table does not change the source notebook. Local JSON restore replaces the table library only after a confirmation. It does not delete existing slide prompts or API keys.

User data is used only for the disclosed notebook-output workflow, not advertising, resale, creditworthiness, or unrelated profiling. The developer has no backend access to users’ local data.
